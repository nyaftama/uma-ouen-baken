# ウマ娘 推しバ券メーカー ALLSTAR edition (UMAMUSUME OSHI-BAKEN MAKER: ALLSTAR Edition)

「ウマ娘 プリティーダービー」の非公式応援ツールです。  
あなただけのオリジナル「推しバ券」をブラウザ上で簡単に発券・印刷用PDF出力・共有できます。

- **Webアプリ**: [https://nyaftama.github.io/uma-ouen-baken/](https://nyaftama.github.io/uma-ouen-baken/)
- **7th in TOKYO edition**: [https://nyaftama.github.io/uma7th-ouen-baken/](https://nyaftama.github.io/uma7th-ouen-baken/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

---

## 主な機能

1. **多彩な検索と発券タイプ対応**
   - キャスト名・キャラクター名・よみがな・タグによる高速検索
   - 「キャスト名優先」「キャラ名優先」の表示切替
   - 単勝・ウマ連・3連複の発券対応（候補リストからの複数選択対応）

2. **バ券カスタマイズ & デザインオプション**
   - キャラクターのイメージカラー反映（メイン/サブカラーの反転対応）
   - レトロな馬券風の「文字をビットマップ化」表示
   - ジュエル数（購入額）の柔軟な調整（100 / 1000単位）

3. **開催情報（レース設定）の自由なカスタマイズ**
   - レース名（皐月賞、有馬記念など）の検索・自動補完および時期別レース一覧選択
   - 開催日、開催レース場（東京、中山、阪神等）、レース番号、グレード（GI, GII, GIII, OPなど）の設定

4. **発券履歴 & 原寸大A4印刷用PDF出力**
   - 発券した推しバ券の履歴自動保存（最大8枚）
   - A4サイズの原寸大印刷用PDFの作成・まとめてダウンロード機能

5. **保存 & シェア**
   - 高解像度での推しバ券画像生成
   - X（旧Twitter）へのワンタップ投稿リンク生成

---

## 使い方

1. **ウマ娘 / キャストを選択する**
   - 検索窓から推しウマ娘またはキャストを検索し、選択して候補リスト（ウマ連・3連複の場合は複数）に追加します。

2. **開催情報を設定する（任意）**
   - 「変更」ボタンからレース名や開催日、レース場などの開催情報を自由にカスタマイズします。

3. **発券する**
   - ジュエル数を調整し、「発券」ボタンを押して推しバ券画像を生成します。

4. **保存・印刷・シェア**
   - 生成された画像を保存してX（Twitter）でシェアしたり、「発券履歴・印刷用PDF」からA4原寸大印刷用PDFを出力できます。
